# UH Student Center Room Booking

CIS 2336 project for booking and making reservations. 

## Run the app

Install Node.js 18 or newer, then run:

```bash
cd myapp
npm install
npm test
npm start
```

Open **http://localhost:3000**. On Windows, you can also double-click
**Start Room Booking.cmd** in this folder. Keep the server window open
while using the app. In PowerShell, use `npm.cmd` if `npm.ps1` is blocked.

See [the app README](myapp/README.md) for the project structure, API
reference, tests, and original assignment instructions.
